# NFSU2 Desktop Launcher (Unofficial)

A small Electron launcher for [nfsu2.xyz](https://nfsu2.xyz/).

## Use

1. Download the Windows portable `.exe` from **Releases**.
2. Place it in a writable folder and run it.
3. In the launcher, open nfsu2.xyz.
4. While online, use the site's **Download all assets** option.
5. Close the app, disconnect from the internet, and relaunch to test offline play.


## Data storage

The app stores its Electron profile in `nfsu2-data` beside the portable `.exe`. Keep that folder with the `.exe` to retain downloaded data and settings.

## Build from source

Requires Windows x64 and Node.js 22.12.0 or newer.

```powershell
npm install
npm start
npm run dist:win:portable
```
